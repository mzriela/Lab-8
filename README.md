# Lab-8
In this lab, I used an ESP32 and my phone to learn how Bluetooth Low Energy (BLE) works. I connected an OLED display to the ESP32 and made it show text. I gave the ESP32 its own Bluetooth name so my phone could find it. When my phone connected, the OLED showed “Connected”. When I sent a message from the Bluefruit Connect app, the OLED showed it with a message number. I also compared BLE with Wi-Fi and learned why BLE is better for small, low-power devices like fitness trackers.
# Required Equipment 
- ESP32 Dev Board
- SSD1306 0.96" OLED Display, 128 x 64
- Breadboard
- Jumper Wires
-  USB Cable
-  A smartphone (iPhone or Android)
# Software
- Visual Studio Code
- PlatformIO
- Serial Monitor
- Bluefruit Connect (Apple users)
- BLE_UART.h file (provided by instructor)
# Safety Instructions
- Disconnect power before modifying circuits.
-	Verify all wiring before powering the circuit.
-	Connect the OLED to 3.3V only.
-	Ensure all grounds are connected.
-	Avoid short circuits
- Keep the workstation organized.
- Only connect to your own ESP32.
